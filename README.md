# Urban-Trends

UrbanTrends – E-Commerce Application

UrbanTrends is a full-stack e-commerce platform built with Angular, LoopBack 4, PostgreSQL
It provides a modern shopping experience with secure authentication, role-based access control, real-time features, and scalable architecture using industry-standard design patterns.


🚀 Tech Stack
Frontend

Angular

Angular Material

Responsive UI / SPA Architecture



Backend

LoopBack 4

PostgreSQL

Arc Sequelize

Authentication & RBAC via Arc MS

Real-time notifications & chat (Arc MS)

Design Patterns:

Repository Pattern

Factory Pattern

Singleton

Dependency Injection

DevOps

Docker

GitHub Actions (CI/CD)

AWS Deployment (EC2)




Testing

Jasmine / Karma (Frontend)

Jest / Mocha / Supertest (Backend)

Unit, Integration




📦 Features
Frontend

User-friendly 

Product listing, filtering, sorting

Cart & Checkout flow

User Profile Dashboard

Order history




Backend

Secure JWT Authentication

Role-Based Access Control (Admin, User)

CRUD for Products, Orders, Cart, Users

Database relationships with Sequelize

Clean architecture using design patterns




🛠️ Project Setup
Clone Repository
git clone git@github.com:VeerpalKaur03/Urban-Trends.git
cd Urban-Trends



Frontend Setup
cd UrbanTrends-Angular/urban-trends
npm install
ng serve




Backend Setup
cd UrbanTrends-Backend/urban-trends-backend
npm install
npm start




🧪 Testing
Run Frontend Tests
ng test

Run Backend Tests
npm test




Includes:

Unit tests for components, services

Integration tests for APIs
